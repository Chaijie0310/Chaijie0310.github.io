# 项目详情模板（复制这个文件）

::: tip 怎么用
把本文件复制成 `docs/projects/你的项目名.md`，然后把下面的内容替换成你的项目。
保留五段结构就行 —— 面试官看学生项目，最想知道的是**你亲手做了什么、卡在哪里、怎么解决的**。
:::

## 项目背景

【待填写】

写清楚三件事：这是什么（课程作业 / 自己想做 / 帮别人做的）、为什么做、
当时想解决什么问题。一两句话就够，不要写成产品发布会。

## 我做了什么

【待填写】

- 负责的部分：例如"首页和列表页的静态还原"、"写了个简单的数据筛选逻辑"
- 用到的技术：例如 HTML / CSS / JavaScript / Vue 3 / Git
- 项目规模：几个人一起做、做了多久、你在其中是什么角色

## 技术方案

【待填写】

重点写**你的判断**，而不是名词堆砌：

- 为什么选这个做法？有没有考虑过另一种？
- 页面结构怎么划分的？样式是怎么组织的？
- 如果是跟着教程做的，哪部分是你自己改的、自己加的？

## 遇到的坑与解决

【待填写】

这一段最能体现真实水平，写具体一点：

1. 现象：例如"手机上打开布局全乱了"
2. 排查：怎么定位到的（开发者工具、看文档、搜报错）
3. 解决：最后改了什么
4. 收获：下次会怎么避免

## 结果

【待填写】

- 完成度：能跑起来的功能有哪些，哪些还没做
- 有没有部署上线？地址是什么？
- 如果能看到效果，放一张截图：`![页面截图](/screenshots/项目名.png)`

## 复盘

【待填写】

- ✅ 做对的地方
- 🔧 现在回看会怎么改
- 📚 通过这个项目学会了什么（这一点对实习生很重要）
