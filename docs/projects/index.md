## 我会怎么写项目

每个项目按同一个结构写，方便你快速判断我的实际水平：

| 部分 | 你会看到什么 |
| --- | --- |
| 项目背景 | 为什么做这个，解决什么问题，是课程作业还是自己想做 |
| 我做了什么 | 具体负责哪些页面 / 功能，用了什么技术 |
| 遇到的坑 | 卡住的地方、怎么查资料、最后怎么解决 |
| 结果 | 能跑起来的功能、完成度、有没有上线 |
| 复盘 | 现在回看哪里做得不好，下一步想怎么改 |

## 大一阶段的诚实说明
