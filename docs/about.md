## 我是谁

我是 **柴杰**，2026 年 9 月入学四川传媒学院，读计算机科学与技术，现在大一。

我选前端的原因很直接：我喜欢"写完就能看到"的东西。写一段代码，刷新一下浏览器，
页面就变了 —— 这种反馈让我愿意反复练。现在我还在打基础，HTML 和 CSS 能写静态页面，
JavaScript 在学，接下来准备系统学 Vue 3。

我清楚自己现在最缺的是**真实项目经验**，所以这个网站的意义不是包装自己，
而是把学习进度、做过的东西、踩过的坑如实记下来。每做完一个项目，我就补一篇详情页。

## 我在找什么

- **岗位**：前端开发实习生（Web 前端、页面开发、小程序方向都可以）
- **地点**：成都，或远程
- **时间**：寒暑假可全职；学期内每周 2–3 天
- **希望团队**：有人愿意带、能让我接触真实项目，哪怕从改样式、修小 bug 开始
- **我的诉求**：把课堂上的东西用到真实业务里，学会怎么做能上线的代码
