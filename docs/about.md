## 我是谁

我是 **柴杰**，目前在上海，做 Web 开发 6 年。

最开始两年做前端，从 jQuery 时代一路迁到 Vue / TypeScript；后来因为业务需要接手后端，
慢慢变成前后端都能独立负责的全栈工程师。我最擅长的事情是**把一个说不清楚的需求，梳理成能落地的技术方案**：
先确认业务目标，再拆模块、定接口、估工期，最后带着复盘把它交付掉。

我不太喜欢"只做分配给我的那部分"。过去几次比较有成就感的经历，都是主动发现瓶颈
（接口慢、发布频繁出错、数据口径不一致），然后推动改成更好的样子。
